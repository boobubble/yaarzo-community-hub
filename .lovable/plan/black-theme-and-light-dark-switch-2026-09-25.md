# Black Theme and Light/Dark Switch

## What will change
- Add a fourth **Black** theme alongside Premium Glass, Cyberpunk, and Neon Glass.
- Keep each theme’s mixed pink, violet, cyan, green, and gold accents while giving Black a deeper neutral base.
- Add a separate icon button for switching between light and dark appearance without replacing the existing theme picker.
- Remember both the selected theme and light/dark choice in the browser.

## Visual treatment
- Dark mode keeps the current deep premium appearance.
- Light mode uses bright neutral surfaces, dark readable text, restrained tinted panels, and the same multi-color accents.
- Buttons, selected navigation, inputs, member details, dialog text, disabled states, and muted labels will retain readable contrast in both modes.

## Verification
- Test all four themes in both light and dark modes.
- Check desktop and mobile for clipping, overflow, and text contrast.
- Confirm theme choices persist after refresh and the existing CodyChat guest/member behavior remains unchanged.
- Confirm the preview build is healthy.
